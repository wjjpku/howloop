# Paper source: arXiv:2609.39892v1

This directory contains the 36-page [public preprint](https://arxiv.org/abs/2609.39892v1) of *Shared Weights, Selected Computations: How Looped Transformers Route What Each Loop Does*. `main.tex`, `references.bib`, and the 21 PDF figure assets correspond to the arXiv v1 source package. `arxiv_v1.pdf` is the PDF served by arXiv.

To compile the source as a standalone LaTeX project, use pdfLaTeX with BibTeX and the bundled style files. Exact source and PDF hashes are recorded in `../provenance/arxiv_v1_manifest.json`.
