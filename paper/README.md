# ICLR 2027 anonymous submission

Open `main.tex` with **pdfLaTeX** (BibTeX bibliography). This folder contains only source files needed to compile the submission.

- `main.tex`: manuscript, unnumbered disclosures, references, and appendices.
- `references.bib`: the single bibliography database.
- `figures/`: the 15 vector PDFs actually referenced by the manuscript.
- The four `.sty` / `.bst` files are unmodified official ICLR 2027 template files.

Keep review mode enabled: do not uncomment or add `\iclrfinalcopy`. Do not change template margins, line spacing, or font size. Edit text and captions in `main.tex`, references in `references.bib`, and replace figure PDFs only when revising those figures.

The compiled submission PDF and author-facing compliance notes are delivered separately, outside this uploadable source folder.
