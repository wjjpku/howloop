# 冻结 J 的连续组合测试

已完成五个 D8L6 骨干 × 两个已有 map fit，无训练、无参数更新。未修改论文。

## 协议
从原生 h6 开始，执行 F(J_b(F(J_a(h6))))。两次 F 分别为 loop index 6 和 7；中间不重置状态、不替换输入、不喂入正确答案。J 作用于所有 token。保留 raw/one/two 的全部九种两步组合，以及每次 J 后、F 前的读出。使用既有训练排除确认集的 512 个图、全部 5120 个起点实例；主统计要求当前及后续 1–4 跳节点两两不同，留下 3200 个实例，不按预测正确性筛选。该分母不同于此前单步实验的 4116。所有 fit 第一步预测与此前存档逐项一致；参数版本保持不变，模型、控制器、数据与代码哈希见每个 fit 的 JSON。

探索性评估复用已有确认图，不宣称为独立新测试集。区间为 5000 次按图配对 bootstrap，两个 fit 在同一次图重采样中共同保留；不代表骨干总体不确定性。

## 解释
现有 map 在未针对连续组合训练的条件下，具有部分两步组合能力。主骨干四种组合均超过相同第一次控制后不加第二次 J 的对照；但组合不是无损的，且交换顺序会影响成功率。不同骨干和不同 map 的可重复使用程度差异明显，不能推广为任意长度、任意顺序的可靠控制。one→two 与 two→one 的最终目标相同，但计算路径和中间状态不同。尚未测试三次及更多连续控制。

完整逐例预测见各 npz；均值、区间、第一步正确子集和答案分布见 summary.json。
